## Hungarian Algorithm Web Tool

Website that allows students to manually run the Hungarian Alogorithm on custom matrices. Built for the Spring 2026 ENGRI 1101 course at Cornell University.

Access: https://ctao6.github.io/hungarian/
Feel free to clone this repository and add additional features such as an automatic solver. This feature was not implemented in the current version as it was built as a learning tool for a college course.
